# Aonagi Website Assets

Production-ready blue-green bamboo garden assets for a GSAP / ScrollTrigger landing page.

- `hero/`: aligned 1920x1080 master and compositing layers
- `plants/`: transparent foreground botanical cutouts
- `effects/`: transparent fog, moon rays, leaves, droplets and particles
- `cat/walk/`: four aligned walk-cycle frames
- `cat/tail/`: three aligned tail-cycle frames
- `webp/`: optimized equivalents for website delivery
- `asset-manifest.json`: dimensions and alpha metadata

Keep PNG files as editing masters. Use WebP versions in production where supported.
